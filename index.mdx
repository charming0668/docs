## 为什么对比 PyTorch 与 JAX？

| 核心维度 | PyTorch 体系 | JAX / Flax 体系 |
| :--- | :--- | :--- |
| **设计哲学** | 面向对象 + 动态命令式（Eager） | 纯函数式编程 + 抽象语法树（JAXPR）变换 |
| **执行模型** | 解释执行，动态构图（可选 `torch.compile`） | 默认 XLA 静态全图编译，算子深度融合优化 |
| **状态机制** | 对象持有权重，原地修改（In-place Mutation） | 无状态与纯函数，参数与计算图解耦 |
| **并行范式** | 手动管理 Batch 轴与分布式通信通信子 | `vmap` 自动向量化、SPMD 张量分片原语 |
