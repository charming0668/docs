为了彻底终结 Linen 带来的状态割裂与心智负担，Google 与 Flax 核心团队推出了革命性的新一代架构：**Flax NNX**。

在包括 **OpenPi（物理机器人具身大模型）** 等最新顶级 JAX 开源项目中，已全面拥抱并采用 Flax NNX 替代传统的 Linen。

---

## 1. NNX 的核心哲学：面向对象与函数式的完美统一

Flax NNX 的设计哲学可以用一句话概括：
> **在编写模型时，享受 PyTorch 般的直观面向对象体验；在进行编译求导时，无缝桥接回 JAX 纯函数的强大变换能力。**

```
[ 开发者视角 ] ───────────────────────────► [ JAX / XLA 视角 ]
nnx.Module (像 PyTorch 一样定义)            JAX Pure Function (纯函数求导)
内部直接包含 self.w, self.linear                ▲
           │                                    │
           ▼                                    │
     nnx.split() (解构) ────────────────────────┘
       ├── GraphDef (纯计算图拓扑结构)
       └── State (可导参数与状态字典)
           │
     nnx.merge() (重构回对象) ◄─────────────────┘
```

## 2. 编写 NNX 模型：找回熟悉的直觉

在 NNX 中定义模块，体验与 PyTorch 几无二致：

```python
from flax import nnx
import jax.numpy as jnp

class NNXMLP(nnx.Module):
    def __init__(self, in_features: int, out_features: int, *, rngs: nnx.Rngs):
        # 1. 像 PyTorch 一样，在 __init__ 中直接挂载子模块与参数！
        self.fc1 = nnx.Linear(in_features, 64, rngs=rngs)
        self.fc2 = nnx.Linear(64, out_features, rngs=rngs)
        self.count = nnx.Variable(0) # 维护非梯度内部状态

    def __call__(self, x):
        # 2. 像 PyTorch 一样直观调用，无需 .apply()，内部直接读写属性！
        self.count.value += 1
        x = nnx.gelu(self.fc1(x))
        return self.fc2(x)

# 实例化模型
model = NNXMLP(in_features=10, out_features=2, rngs=nnx.Rngs(0))

# 直接像函数一样执行！
dummy_x = jnp.ones((1, 10))
out = model(dummy_x)
print("直接前向输出形状:", out.shape) # (1, 2)
print("内部计数状态自增:", model.count.value) # 1
```

## 3. 核心机制：解构（split）与重构（merge）

NNX 如何既支持对象内部的原地修改，又能喂给严格要求纯函数的 `jax.jit` 和 `jax.grad` 呢？关键就在于 `nnx.split` 与 `nnx.merge`。

### 3.1 状态分离与组装
```python
# 将有状态的 model 解构为：纯计算图结构 (GraphDef) 与 纯数据字典 (State)
graphdef, state = nnx.split(model)

# 此时 state 是一个纯 PyTree，可以随意进行 JAX 变换与多卡通信！
print("可学习参数集合:", state.filter(nnx.Param))

# 使用全新的纯数据重新组装回完整的面向对象模型：
new_model = nnx.merge(graphdef, state)
```

## 4. 实战：NNX 训练循环与灵活参数过滤（DiffState）

在真实工业项目中（如 OpenPi 的训练代码 `scripts/train.py`），我们经常需要**冻结某些层（Freeze layers）**或**只更新特定参数（如 LoRA）**。在 NNX 中，通过 `DiffState` 和参数过滤器极其简单直观：

```python
import jax
from flax import nnx
import optax

# 1. 初始化模型与优化器
model = NNXMLP(10, 2, rngs=nnx.Rngs(0))
optimizer = nnx.Optimizer(model, optax.adam(1e-3))

# 2. 纯函数损失函数
def loss_fn(model: NNXMLP, x, y):
    pred = model(x)
    return jnp.mean((pred - y) ** 2)

# 3. 核心训练步进函数
@nnx.jit
def train_step(model: NNXMLP, optimizer: nnx.Optimizer, x, y):
    # 使用 DiffState 过滤出所有可训练的参数 (nnx.Param) 进行求导
    diff_state = nnx.DiffState(0, nnx.Param)
    
    # 自动计算损失与针对可训练参数的梯度
    loss, grads = nnx.value_and_grad(loss_fn, argnums=diff_state)(model, x, y)
    
    # 优化器内部自动完成梯度更新并同步原地回写模型
    optimizer.update(grads)
    return loss

# 4. 执行训练步
loss = train_step(model, optimizer, dummy_x, jnp.zeros((1, 2)))
print("Step 训练损失:", loss)
```

## 5. Linen 与 NNX 全面对比

| 特性维度 | Flax Linen (旧代) | Flax NNX (新一代 / OpenPi 标配) |
| :--- | :--- | :--- |
| **编程范式** | 彻底无状态函数式（类只是 Blueprint） | 混合范式：面向对象结构 + 函数式内核 |
| **权重存储位置** | 外部分离的 `variables` 字典 | 模块内部持有的属性（如 `self.fc1`） |
| **前向调用语法** | `model.apply(variables, x)` | 直接调用：`model(x)` |
| **层冻结与过滤** | 极其繁琐的字典正则匹配与路径裁剪 | 原生过滤器：`state.filter(nnx.Param)` |
| **生态演进趋势** | 维护阶段，复杂场景负担重 | 官方大力演进推荐，前沿大模型新标配 |

## 本章小结

1. **Flax NNX** 成功打破了面向对象与函数式编程的壁垒；
2. 借由 `split` 与 `merge`，NNX 可以在运行时随心所欲地提取纯数据或组装对象；
3. `nnx.jit` 与 `DiffState` 为复杂的工业级训练提供了极简的 API 体验。
